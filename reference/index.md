# Package index

## Main functions

- [`desc_stats()`](https://docs.ropensci.org/pkgstats/reference/desc_stats.md)
  : Statistics from DESCRIPTION files

- [`loc_stats()`](https://docs.ropensci.org/pkgstats/reference/loc_stats.md)
  : Internal calculation of Lines-of-Code Statistics

- [`pkgstats()`](https://docs.ropensci.org/pkgstats/reference/pkgstats.md)
  : Analyse statistics of one R package

- [`pkgstats_summary()`](https://docs.ropensci.org/pkgstats/reference/pkgstats_summary.md)
  :

  Condense the output of `pkgstats` to summary statistics only

- [`rd_stats()`](https://docs.ropensci.org/pkgstats/reference/rd_stats.md)
  : Stats from '.Rd' files

## Code Tagging Functions

- [`ctags_install()`](https://docs.ropensci.org/pkgstats/reference/ctags_install.md)
  : Install 'ctags' from a clone of the 'git' repository
- [`ctags_test()`](https://docs.ropensci.org/pkgstats/reference/ctags_test.md)
  : test a 'ctags' installation
- [`tags_data()`](https://docs.ropensci.org/pkgstats/reference/tags_data.md)
  : use ctags and gtags to parse call data

## Archive Trawl Functions

- [`dl_pkgstats_data()`](https://docs.ropensci.org/pkgstats/reference/dl_pkgstats_data.md)
  : Download latest version of 'pkgstats' data

- [`pkgstats_cran_current_from_full()`](https://docs.ropensci.org/pkgstats/reference/pkgstats_cran_current_from_full.md)
  :

  Reduce `data.frame` of full CRAN archive data to current packages
  only.

- [`pkgstats_fns_from_archive()`](https://docs.ropensci.org/pkgstats/reference/pkgstats_fns_from_archive.md)
  : Trawl a local CRAN archive to extract function names only from all
  packages

- [`pkgstats_fns_update()`](https://docs.ropensci.org/pkgstats/reference/pkgstats_fns_update.md)
  : Update function names data from previous data and newly updated CRAN
  packages only.

- [`pkgstats_from_archive()`](https://docs.ropensci.org/pkgstats/reference/pkgstats_from_archive.md)
  : Trawl a local CRAN archive and extract statistics from all packages

- [`pkgstats_update()`](https://docs.ropensci.org/pkgstats/reference/pkgstats_update.md)
  : Update pkgstats\` data on GitHub release

## Additional functions

- [`extract_tarball()`](https://docs.ropensci.org/pkgstats/reference/extract_tarball.md)
  : Extract tarball of a package into temp directory and return path to
  extracted package
- [`pkgstats_fn_names()`](https://docs.ropensci.org/pkgstats/reference/pkgstats_fn_names.md)
  : Extract names of all functions for one R package

## Visualisation

- [`plot_network()`](https://docs.ropensci.org/pkgstats/reference/plot_network.md)
  : Plot interactive visualisation of object-relationship network of
  package.
